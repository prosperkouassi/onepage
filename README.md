# Bardebabi

Landing page de démonstration Next.js (App Router, React, TypeScript).

## Démarrer

```bash
npm install
npm run dev
```

Ouvrir http://localhost:3000. Vérifier avec `npm run lint`, `npm run typecheck` et `npm run build`.

## Avant publication commerciale

Remplacer les visuels d'illustration par des photos autorisées, renseigner l'adresse, les horaires, les coordonnées, la carte et les tarifs, puis réviser les métadonnées et l'indexation dans `src/app/layout.tsx`.
